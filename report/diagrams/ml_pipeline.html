StayMart Content-Based & Behavioral ML Recommendation Pipeline
Step 1: Data Ingestion
MySQL Aggregation
Extract approved properties & products along with historical interactions from user_behaviors table.
➔
Step 2: Feature Engineering
Text Synthesis
Construct composite document: Title + Description + Category + City + Area + Price Tier + Amenities tokens.
➔
Step 3: Vectorization
TF-IDF Sparse Matrix
Scikit-learn TfidfVectorizer computes term frequency-inverse document frequency vectors (n-grams: 1-2).
➔
Step 4: Similarity Computation
Cosine Similarity
Compute dot product matrix between candidate vectors and user profile weighted interaction vectors.
➔
Step 5: Hybrid Re-Ranking
Top-K Recommendations
Apply locality filter (target city), popularity prior, and recency damping; return JSON to Spring Boot REST.
